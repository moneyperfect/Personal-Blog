Architecture

工作流管线

五个 Agent 按序执行，每个环节的输出是下一个环节的输入，形成线性管线。

📊
Agent 01 — Selection
Topic Agent
读取 Obsidian 中的历史评分数据，基于「选题共鸣 / 标题钩子 / 内容质量 / 可读性」四个维度进行动态加权，结合时间衰减机制自动选择高潜力选题。
Obsidian 数据读取 四维加权算法 时间衰减函数
✍️
Agent 02 — Writing
Writing Agent
自动生成 1500-2500 字长文内容，覆盖多个信息维度，自动补全工具介绍、产品背景与引用信息，确保内容深度与广度。
1500-2500 字长文 多维度覆盖 自动补全引用
🔍
Agent 03 — Review
AI Review Agent
自动扫描 AI 生成痕迹与低质量表达（固定套话、重复结构等），检测后自动进行二次改写与风格优化，确保内容自然度。
AI 痕迹检测 自动改写 风格优化
🎨
Agent 04 — Visual
Visual Agent
根据不同内容类型自动匹配封面风格，调用 VibeImg API（底层 gpt-image-2）生成封面与配图，自动生成中文提示词与标题视觉元素。
VibeImg API gpt-image-2 风格自动匹配 中文提示词
🚀
Agent 05 — Publish
Publish Agent
通过微信公众号 API 自动上传草稿箱，经腾讯云 SCF 构建固定出口 IP 中转层，解决 WSL2 环境下网络出口漂移问题，确保稳定连通。
微信公众号 API 腾讯云 SCF 固定出口 IP WSL2 适配
Closed Loop

数据闭环系统

发布不是终点。用户在微信端的行为数据会自动回流至 Obsidian，重新参与选题权重计算，让每一次发布都成为下一次选题的养分。

Impact & Proof

使用证明与影响力

以下是系统实际运行的关键指标与技术深度证明。

高 Token 消耗场景

每日 3 次自动运行，每次涉及 5 个 Agent 的连续调用。Writing Agent 单次生成 1500-2500 字长文，AI Review Agent 进行全文扫描与二次改写，单日 Token 消耗量级显著。

长期稳定运行

系统已长期稳定运行，每日自动执行。通过腾讯云 SCF 固定出口 IP 解决了 WSL2 网络漂移问题，通过 Obsidian 实现了数据持久化与跨会话记忆。

多模型协作实验

日常进行 Prompt 优化、模型路由实验、多 Agent 协作与生成质量优化。涉及 Claude Code、Codex、GPT 系列模型的深度使用与对比测试。

数据驱动迭代

四维评分体系（选题共鸣/标题钩子/内容质量/可读性）+ 时间衰减权重，让系统具备自我进化能力。每次评分回流都优化下一轮选题决策。

Verification

可验证的技术细节

  • ①
    定时任务系统 — 每天 8:00 / 11:00 / 16:00 自动触发，通过 Hermes Agent 的 cron job 机制执行，可通过 session search 检索历史执行记录。
  • ②
    评分数据持久化 — 所有评分记录存储在 Obsidian vault 中，包含时间戳、四个维度评分、综合加权分，可追溯完整历史。
  • ③
    API 中转架构 — 腾讯云 SCF 函数计算作为公众号 API 的固定出口 IP 层（1.12.46.117），解决了 WSL2 + Clash 代理环境下的 IP 漂移问题。
  • ④
    AI 检测与自动改写 — 内置 AI 写作特征识别模块，扫描固定套话、重复句式、逻辑断层等 12 类 AI 痕迹，检测后自动触发二次改写流程。
  • ⑤
    图像生成管线 — 按选题类型匹配 4 种封面风格模板，自动生成中文提示词，调用 VibeImg API（gpt-image-2）生成 2-3 张配图，每次消耗 10 credits。
